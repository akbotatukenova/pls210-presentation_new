# PLS210 — Drawing the Line

This is a static GitHub Pages presentation site.

## Files

- `index.html` — complete presentation
- `style.css` — all styling
- `script.js` — slide navigation and horse animation
- `assets/horse-rider-cartoon.jpg` — moving horse visual
- `assets/mountain-horses.jpg` — original uploaded landscape photo (not used on the cover anymore)

## Upload to GitHub Pages

1. Create a **public** GitHub repository.
2. Upload the contents of this folder so that `index.html` sits in the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Save and wait for the site to publish.

## Navigation

- `→` next slide
- `←` previous slide
- `Space` next slide
- swipe left/right on touch devices
